**一句话结论**：本期没有必读或值得看，宁缺毋滥。真正值得记的是两条**测量**，都说明「打分的那一方」在我们最需要它的地方靠不住：

1. **成对 VLM 评判会随训练越来越分不出好坏。** RAP-Walk 在 Wan2.1-1.3B 的视频 GRPO 里，用 Qwen3-VL-235B 两两比较同组 12 条视频。训练从开始到后期，评判的平均清晰度 0.261 → 0.132，近平局的比例 52.6% → 67.3%（Tab.1，原文核对）。也就是说，到后期三分之二的比较接近抛硬币。它提出的新聚合方法本身是重做：在 BT 假设下约等于「胜率 + BT 分 − 循环惩罚」，我的玩具实验里它和普通胜率 advantage 相关 0.93–0.999（实测）。
2. **音画一致性的自动指标和人基本对不上，连新训的 RM 也只到人类上限的一半。** AVC-Reward 放出了 706 条、每条 3 人标注的 AVC-Benchmark。13 个现有指标（DeSync、JavisScore、ImageBind、AV-Align、Gemini-3.1-Pro 等）与人的 Spearman 全部 ≤ 0.23（DeSync 0.06、JavisScore 0.15、Gemini-3.1-Pro 0.12）；作者自己的 AVC-Reward 是 0.244，三人标注之间的上限是 0.497（Tab.2）。我用官方脚本和官方 CSV 重算，这些数字逐项对得上（实测，`benchmark_eval.py`）。

**对我们训练的含义**：

- **音视频世界模型上 RL（最直接）**：现在没有一个自动的音画一致性 reward 和人的相关超过 0.25。上 RL 前，把三个开源候选——AVC-Reward（RM + LTX-2 LoRA + bench 已放）、SyncReward（80K 人评）、VA-Judger——放在**同一份人评集**上比一遍再选；训练中必须保留人评，不能只看自动分。作者把它接进 OmniNFT（LTX-2）后，100 个 prompt × 3 人的盲评对原版 OmniNFT 胜 58–73%，但文本对齐（IB-TV、CLIP）三个基准都下降了，也没报运动幅度。
- **用 VLM 成对评判做视频 GRPO 时**：每一步记录每组的平均清晰度和近平局占比，超过 60% 就当作信号枯竭的报警线；该做的是换或刷新评判器、增大组内差异，而不是换聚合器。DD 一定要对照 base 报——RAP-Walk 在 1.3B 上，除 Rank Centrality 外，所有成对和逐点 GRPO 变体的 DD 都远低于 base 的 50（6.0–29.8）。
- **DMD / 少步**：NPO（2610.21125）给了一个不动学生权重的选项：生成器冻结，只在初始噪声上学一个「按 reward 倾斜」的分布。1 步 SD-Turbo 上 aesthetic 6.12 → 6.52，推理成本是 base 的 2.6 倍（BoN-32 要 44 倍），LPIPS 多样性不低于 base（Tab.1、Fig.4/9，5 个种子）。但 reward 只有 aesthetic 和 JPEG 压缩率，没和少步 RL 的最强基线正面比。对我们：如果 DMD 学生直接做 RL 塌缩，先跑「噪声策略 vs 直接微调」同 reward 对照；上限受生成器本身能产生什么限制（P5）。
- **AR / 双向视频**：RPO（2610.22282）把探索从「往采样轨迹里加噪」改成「训练时随机屏蔽部分注意力块」，推理时去掉屏蔽。Wan2.2-5B 上 VBench 总分 81.61 → 82.00，训练 24.1 GPU-h（Flow-GRPO 75.4），但只有一个种子、算力没对齐，表里没报 RPO 的运动幅度。了解即可。

### 跨篇收敛（G5：本期 + 近 7 天存疑 / 了解即可）

- **收敛 4 加一个独立来源（AV）**：「笼统或单项的自动分数测不出具体属性、对不上人」。原有 IsoVRBench（帧顺序，最好 RM 60.8%）、VA-Judger（AV 单项指标一致率 50–57%）、SyncReward（优化 AV-Align 自身指标 0.306 → 0.420，人偏好反降）；本期 **AVC-Reward**（706 条人评，13 个指标 ρ ≤ 0.23，我复算一致）。四个来源不同组、互不依赖（AVC-Reward 引用了 VA-Judger 但没用它的数据）。共同的边界：两个 AV bench 都是 RM 作者按自己的协议标的，有主场优势；没有一篇把 AVC-Reward、SyncReward、VA-Judger 放在同一份人评上比。可信度维持「独立印证·中」。
- **新观察（只有 2 个来源，不立原理候选）**：评判信号会在训练中衰减。RAP-Walk（on-policy 成对 VLM，近平局 52.6% → 67.3%）、Self-Verifier（冻结裁判与外部评测相关 0.76 → 0.18）。还差一个独立来源；本质上是格②「组内同分无信号」的动态版本。
- **P10 不计**：RPO 用屏蔽注意力的 rollout 训练、推理却走 dense 路径，增益仍然迁移（单种子）。它是 PG 而不是 NFT，没有回归参考，检验不了 P10。
