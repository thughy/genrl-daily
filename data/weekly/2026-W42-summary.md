## 一句话
本周学到的主要不是新的更新规则，而是**信号什么时候可信**：NFT 的参考和训练状态一旦和采样器对不上，就多出一项与 reward 无关的推力（P10）；只有受控对比才可归因（P11）；一个笼统的自动分数测不出具体属性，音画一致性尤其如此（收敛 4，本周四个独立来源）。同时查出我们自己两个系统偏差——低估发现类论文、低估论文的严谨度——和一个流程缺陷：run 一断就整期不可见（本周 2 次）。

## 1. 证实 / 推翻
1. **P10 候选（NFT 参考与训练状态须匹配采样器）——方向证实，后果被限定。** GuidanceNFT 玩具里，参考取条件预测时多出的项 RMS 0.32，是真正 reward 更新 0.13 的约 2.4 倍；有效占据格 182 → 8（参考正确时 73）（2610.15856 §3 / App.B.2，原文核对）。**我用官方代码在 CPU 上复现了错配臂：183.8 → 8.4，与论文一致（实测）；参考正确的对照臂没跑完，73 未复现。** Fork-NFT：22B 八步 AR 音视频，端点重加噪 JavisScore 0.162，低于不训的 0.186（原文核对）。**新边界**：Astrolabe 同样是端点重加噪 NFT，在 3 个 4 步 AR 基座上都没跌破基座（VBench Total +0.05 / +1.71 / +0.42），但要先去掉 NFT 的自适应权重（否则约 50 步后爆炸），且评测用的是训练 reward（2603.17051，原文核对）。⇒ P10 应写成「会多出一项，后果要测」，不是「必崩」（推断）。
2. **P11 候选（受控对比才可归因）——小幅加强，一处更正。** 我们写过 D2G「单次运行」，**错了**：Stage II 重复了 3 个种子（未报方差），另有 15 位专家双盲人评 300 对（κ=0.78，胜率 82.5%）（原文核对）。Astrolabe 的 clip 级共享前缀分组只是弱旁证，且公开代码里找不到这个分组（实测读代码）。可信度维持「中低」。
3. **收敛 4（笼统自动分数测不出具体属性）——加强。** PhyMetric 全文读后降为旁证（VLM 物理裁判与人的场景级 Spearman 最高 0.293，不支持「针对性提问更贴人」）。**10-16 新增 AVC-Reward**：706 条人评 bench 上 13 个现有音画一致性指标与人 ρ 全部 ≤ 0.23，作者的 RM 0.244、人类上限 0.497（我用官方脚本复算一致，实测）。独立来源：IsoVRBench、VA-Judger、SyncReward、AVC-Reward。
4. **「偏好基准的生成器身份捷径」有边界。** IsoVRBench：成对偏好基准 74–78% 的标签可由生成器身份预测（原文核对）；SyncReward 单条打分 bench 上生成器身份只解释 17.4% 方差（实测）。⇒ 严重程度取决于基准怎么构造（推断）。
5. **评判信号会随训练衰减（新观察，2 个来源）。** RAP-Walk：on-policy 视频 GRPO 里 235B VLM 成对评判的近平局占比 52.6% → 67.3%、清晰度 0.261 → 0.132（Tab.1，原文核对）；Self-Verifier：冻结裁判与外部评测相关 0.76 → 0.18（原文核对）。还差一个独立来源，不立原理候选。
6. **Self-Verifier：自奖励失败拆成 capture（共享权重，探针 AUC 0.812 → 0.630）和 staleness 两种机制**；自标签刷新也不管用（峰值 0.50 → 0.19）（原文核对，5 种子）。CoRe 的「共演化 RM」要加限定：必须有独立标签。
7. **被推翻 / 限定**：「规则 / 几何 reward 最难被 hack」加限定，会被「降低任务难度」绕过（GeoFix、SpatialCritic，原文核对）；「视频偏好基准准确率高 ⇒ RM 能感知属性」被推翻（IsoVRBench）；「换聚合器能救成对 GRPO」不成立——RAP-Walk 在 BT 下约等于胜率 + BT 分，玩具里与胜率 advantage 相关 0.93–0.999（实测）。

## 2. 各线最强基线（逐线一句；本周全部不变）
- L1 可微反传：ReFL（Protocol O）。· L2 回归 reward 梯度目标：DiffusionOPSD。· L3 前向回归 / NFT：默认 DiffusionNFT；子线 CFG 用 GuidanceNFT（代码已出）、AWR 用 FlowAWR、AR 少步视频用 Astrolabe（证据弱）、联合 AV 用 OmniNFT。· L4 GRPO：无单一最强（RPO、D2G、MaskSense 都没和 ExploreNet / CAST 同协议比）。· L5 DPO：无可信最强。· L6 统一模型：自奖励参照协议 = 锁快照 + 1/16 外部锚。· L7 RM / 评测：上 RL 前必测 IsoVRBench Shuffle / Hold；AV 同步 / 一致性在同一人评集上比 SyncReward-Bench、VA-Judger、AVC-Benchmark。· L8 视频一致性：几何 reward 要加相机运动幅度对照。
